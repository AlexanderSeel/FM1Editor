# Synthetic DX7 SysEx compatibility fixtures

The compatibility corpus in `src/sysex/syntheticFixtureCorpus.ts` is generated entirely from repository-authored parameter values and the FM1 Editor DX7 encoders.

It contains no extracted factory patches, commercial patch data, community bank content or user-provided voice data. The source and generated byte sequences are distributed under the repository's MIT license.

## Covered cases

- valid 163-byte Yamaha single-voice message on MIDI channel 16;
- valid 4,104-byte 32-voice bank on MIDI channel 9;
- 32 distinct voices spanning algorithms 1–32 and varied legal parameter ranges;
- checksum-valid legacy single and bank messages using reserved breakpoint `127` and detune `15`;
- stale-checksum rejection;
- unsupported-manufacturer diagnostics using the non-commercial `0x7D` manufacturer ID;
- truncated message detection;
- nested `F0` recovery;
- mixed-file salvage with padding, stray `F7`, supported messages, unsupported messages, checksum errors and an incomplete tail.

Every fixture declares expected complete-message counts, supported-message counts and ordered diagnostic codes. Tests also verify that analysis does not mutate the original bytes and that strict import remains fatal for nested or truncated messages.
